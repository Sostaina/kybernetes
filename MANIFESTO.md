# Manifiesto

> **Placeholder.** Este es el alma del repo — la raíz filosófica. El PO trae su versión y la
> reemplaza acá. Mientras tanto, los ejes que orientan `kybernetes`:

- **Cibernética de 2º orden.** El sistema se observa y se regula a sí mismo. El `retro-ciclo` es el
  sistema mirándose; el `flujo` es el bucle de control. El observador es parte del sistema.
- **Viable System Model (Beer).** Cada parte es un sistema viable recursivo: tiene su **frontera**,
  su autonomía, sus bucles. Un repo es una recursión de sistemas viables.
- **Variedad requisita (Ashby).** La disciplina existe para darle al sistema la variedad suficiente
  para manejar la variedad del trabajo. Las fronteras atenúan/amplifican esa variedad.
- **Amplificar, no reemplazar.** Las máquinas que ahora escriben código son un **subsistema** en el
  loop, no un autocompletado. La colaboración humano-máquina amplifica al humano.
- **Fronteras primero.** Lo que separa un sistema viable de su entorno es su frontera. Gobernarlas
  es gobernar el sistema.
